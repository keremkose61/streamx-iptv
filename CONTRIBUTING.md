# Contributing Guidelines

## Commit Convention
We follow the Conventional Commits specification:
- `feat:` New features
- `fix:` Bug fixes
- `docs:` Documentation modifications
- `refactor:` Code restructuring without functional alterations
- `test:` Test additions or corrections
- `chore:` Maintenance, build, and configuration adjustments
- `security:` Security enhancements or vulnerability fixes

## Code Quality Standards
- All code must include tests verifying the intended behavior.
- Ensure linting passes cleanly across all touched workspace packages.
